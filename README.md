# Managing Devices in Microsoft Intune — A Practical Guide for SMBs
Last updated: 15/10/2026

Part of the **Microsoft 365 Security Foundations** series — practical, hands-on guides for securing Microsoft 365 as a small or growing business.

A hands-on guide to enrolling and securing devices across Windows, Linux, and iOS using Microsoft Intune, written for small and medium businesses managing a mixed fleet of personal and corporate-owned devices.

The steps come from hands-on configuration work, not from theory. Where a decision involves a trade-off, such as cost, team size or what's realistic for a small company, the guide calls it out so you can make the right call for your own situation. Microsoft's ecosystem can be intimidating, but hopefully this guide will save you some time!

**Note:** Because Intune and Defender are closely integrated, some device security configurations are covered in the Defender repository of this series. See also: [Microsoft Defender Threat Protection Guide](https://github.com/LeventKaraagac/microsoft-defender-threat-protection-guide).

## What's covered

1. [Device Enrollment](./01-device-enrollment/) — Linux (Ubuntu), iOS (corporate and BYOD), and Windows (Home edition)
2. [Compliance Policies](./02-compliance-policies/) — Windows, Linux, and iOS (corporate and BYOD), including Windows Home-edition constraints and non-compliance notifications
3. [App Protection Policies](./03-app-protection-policies/) — *(documentation pending)*

## Who this is for

Anyone managing a small, mixed device fleet — a mix of corporate-owned and personal devices across different operating systems — who needs a working compliance baseline without assuming every device is a fully managed, enterprise-edition machine.
